# 彡 Sketch Book 彡☆
> A cozy, retro-minimalist desktop doodling station built entirely with native web technologies. 

`Sketch Book` combines a lo-fi notebook aesthetic with a functional, responsive drawing canvas. Put on some pixelated beats, pick your favorite pastel ink, and start sketching across multiple pages.

---

## ✨ Features

* 🎨 **Interactive Canvas:** Smooth, low-latency sketching with customizable ink colors, preset pastel palettes, and a flood-fill paint bucket.
* ✏️ **Vibe-Matching Cursors:** Your mouse cursor dynamically shifts shape into an SVG icon of your active tool (Pencil, Bucket, Text, or Eraser) with precision hot-spots.
* 🎵 **In-App Retro Synth:** A native Web Audio API chiptune synthesizer engine playing custom loopable pixel tracks with volume and playback controls.
* 📖 **Multi-Page Layout & History:** Sketch across an infinite book with animated page-flipping, complete with local canvas caching and full Undo/Redo (`↩️` / `↪️`) support.
* 🖥️ **Fully Responsive Viewport:** Auto-scaling vector layouts and dynamically recalibrated canvas grids ensure the application looks perfect on any screen size.

---

## 🛠️ Built With

* **HTML5 Canvas** - Vectorized rendering engine and pixel manipulation (Flood Fill).
* **Web Audio API** - Oscillator-based native synthesis for lo-fi tracks.
* **Vanilla JavaScript & CSS3** - Zero-dependency, viewport-locked styling and history stack management.
